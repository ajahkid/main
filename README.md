# Student Grade Calculator\n\nStudent Grade Calculator is a C++ console application for collecting homework and exam results and presenting each student's final point. The project demonstrates a Person class, overloaded input/output, and the rule of three.\n\n## Basic calculation formula\n\nFor the average calculation, the final point is calculated from all homework results and the exam result:\n\nFinal (Average) = (HW1 + HW2 + ... + HWn + Exam) / (n + 1)\n\nScores are expected to be in the range 0 to 10.\n
